Este repositorio guarda todo el proceso de programación del Robot balancín seguidor de línea versión 1.
Esta primera versión logra mantenerse en equilibrio, pero le cuesta desplazarse de forma estable. Por lo que
si bien se logró hacer que siga la línea, la limitante está en la inestabilidad del propio balancín al avanzar.
Proyecto completo: https://sites.google.com/usach.cl/rai-lab/proyectos?authuser=2

El proyecto fue programado por partes, en orden y de forma escalable y progresiva. Por lo tanto,
el código 1 fue el primero y más básico y el 9 el último y que consiste en la programación del proyecto final.

Cada código tiene un comentario donde se indica la finalidad del código, el procedimiento para usarlo
y la metodología de calibración en caso de que se hayan realizado pruebas.

En general, hay comentes a lo largo de todo el código para enterder e interpretar la función de cada bloque de código.

Hay códigos que tienen una versión 1, versión 2, etc. Todas las versiones hacen exactamente lo mismo, solo que cada versión
siguiente es una mejora del código anterior.
